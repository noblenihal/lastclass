3. DESCRIBE THE CHANGES/UPDATES MADE IN THE DEPLOYED VERSION
================================================================
LastClass turns any topic into a five-level climb and ends by making the
learner teach it to a class that asks questions back.

Enter a topic, a personal interest, and how deep to go (Basic / Medium /
Advanced). Gemini breaks the topic into a prerequisite concept graph,
classifies it as theory/practical/hybrid, and generates five levels titled
for that specific topic: Watch, Compare, Picture, Do, Teach.

Depth genuinely changes the curriculum rather than the wording. "Gravity" at
Basic returns Earth's Invisible Pull, Bigger Objects Pull Harder, Air Pushing
Back; the same topic at Advanced returns the Equivalence Principle, the
Stress-Energy Tensor and the Einstein Field Equations.

The learner can also paste something they have written about the topic.
Gemini reads it, judges their real level from how they use terminology and
what they omit, and seeds the concept map with starting mastery values — so
the map opens with real signal instead of zeros. Confident-sounding but wrong
prose earns no mastery.

The learner model is a live concept map. Each node carries a mastery value
that moves only on real evidence of what the learner did — never a preset.
Brightness encodes mastery; a pulsing rose ring marks a concept the class
still has questions about.

Level 5 is the Classroom. The learner explains the topic out loud (speech
recognition, with a typed fallback). Five animal students listen, then raise
their hands — and the questions are generated from two merged signals: the
learner's actual transcript, and their weakest nodes on the concept graph.
Each character probes a different way an explanation fails:

  Bruno (puppy)     — catches undefined jargon
  Prof. Hoot (owl)  — hunts the uncovered edge case
  Ria (fox)         — demands a real-world application
  Tito (tortoise)   — catches the skipped step
  Kiki (parrot)     — repeats the explanation back with one plausible error
                      planted in it; the learner passes only by catching it

Each question is spoken aloud in that character's own voice. The learner can
Explain (answer it), Ask the Master, Skip for now (the hand stays up as
visible debt), or End class.

Ask the Master is the stuck button, and it is deliberately not a cheat. The
Master teaches the LEARNER in text — an explanation at their depth using their
interest domain, the points their answer must hit, and the common trap — but
never answers the student. The learner still has to turn round and explain it
themselves, and an assisted answer earns half the mastery of one they reached
alone. The report card names which answers needed help. Answers are judged in character, and the verdict moves that concept's
mastery on the map. Hands still up at the end become the report card and pull
mastery down. There is no separate quiz anywhere in the product — teaching is
the assessment.

Built and deployed in phases; every phase is a working, deployed increment.
  Phase 0 — scaffold, repo, deploy pipeline
  Phase 1 — concept graph, five-level ladder, live mastery map
  Phase 2 — the Classroom (teach-back, raised hands, spoken characters)
  Phase 3 — persistent workspace UI, legible learning-path map, depth
            calibration and level detection from a writing sample

4. GEN AI SERVICES UTILISED, AND WHERE
================================================================
Google Gemini API (generativelanguage.googleapis.com) — the only AI provider.
All calls run server-side in Next.js route handlers; the API key is stored as
an encrypted Vercel environment variable and never reaches the browser.

MODEL: gemini-3.7-flash — structured JSON output (responseSchema-constrained,
so responses are guaranteed-parseable rather than prompt-and-hope)

  /api/curriculum      Breaks a free-text topic into a prerequisite concept
                       graph, classifies it THEORY / PRACTICAL / HYBRID with a
                       stated reason, writes five topic-specific level titles
                       pitched at the requested depth, and — when the learner
                       pastes a writing sample — judges their real level from
                       it and seeds per-concept starting mastery.

  All content prompts share one learner-context block (lib/context.ts): the
  depth register, the level detected from their writing, their interest domain
  and the live mastery map. So the class interrogates a 10-year-old in
  10-year-old terms and an undergraduate in formal ones, from the same
  explanation.

  /api/classroom/doubts Reads the learner's spoken explanation together with
                       their current mastery values and generates the questions
                       the class raises — each assigned to the character whose
                       probe style fits, tagged with a severity and the concept
                       it targets.

  /api/classroom/mentor Teaches the learner when they are stuck on a student's
                       question: a depth-matched explanation, the key points
                       their answer must contain, and the usual misconception.
                       Text only, and it never answers the student for them.

  /api/classroom/judge  Judges the learner's answer in the character's own
                       voice and, when the answer misses, returns the follow-up
                       that same character presses with — narrowed onto the
                       exact gap. The verdict is what moves the concept map.
                       Follow-ups ride back in the same response, so the
                       back-and-forth needs no sockets and no extra latency;
                       session state lives client-side and the server stays
                       stateless.

MODEL: gemini-3.1-flash-tts-preview — text to speech

  /api/tts             Speaks every character line in a distinct prebuilt
                       voice with a per-character delivery direction. Gemini
                       returns raw 24kHz PCM, which is wrapped in a WAV header
                       server-side so the browser can play it.

MODEL: gemini-3.7-flash (vision) — verified working, wired in Phase 4

  /api/assess/vision   Camera proof-of-work for practical topics: the learner
                       photographs their attempt and Gemini grades it against
                       a rubric, naming the step that failed.

Browser Web Speech API is used for speech-to-text only (not a Gen AI service);
a typed fallback is always available since it is Chrome-only.

NOTHING IN THE APP IS MOCKED OR HARDCODED. Every concept graph, level title,
question, character reply and mastery change is produced by a live Gemini call
at runtime.
